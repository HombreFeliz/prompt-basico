# Página Web de Fotografía - FotoEstudio

Este proyecto es una página web completa para un negocio de fotografía, desarrollada con HTML, CSS y JavaScript. La página incluye varias secciones como galería de fotos, servicios ofrecidos, información sobre el fotógrafo y un formulario de contacto.

## Características

- **Diseño Responsivo**: Se adapta a diferentes tamaños de pantalla (móviles, tablets y escritorio).
- **Galería Interactiva**: Muestra el trabajo fotográfico con un visor modal para ver las imágenes en detalle.
- **Formulario de Contacto**: Permite a los visitantes enviar mensajes directamente desde la web.
- **Navegación Suave**: Desplazamiento suave entre secciones para una mejor experiencia de usuario.
- **Animaciones**: Efectos visuales sutiles para mejorar la interacción del usuario.

## Estructura de Archivos

- `index.html`: Estructura principal de la página web.
- `styles.css`: Estilos CSS para el diseño y la apariencia visual.
- `script.js`: Funcionalidades interactivas implementadas con JavaScript.

## Secciones de la Página

1. **Inicio**: Presentación principal con una imagen de fondo y un llamado a la acción.
2. **Galería**: Muestra del trabajo fotográfico con imágenes organizadas en una cuadrícula.
3. **Servicios**: Descripción de los servicios ofrecidos por el fotógrafo.
4. **Sobre Mí**: Información personal y profesional sobre el fotógrafo.
5. **Contacto**: Formulario para que los visitantes puedan enviar mensajes.

## Cómo Usar

1. Descarga o clona este repositorio.
2. Abre el archivo `index.html` en tu navegador web preferido.
3. Para un proyecto real, reemplaza las imágenes de muestra con tus propias fotografías.
4. Personaliza el contenido según las necesidades específicas de tu negocio de fotografía.

## Personalización

- **Imágenes**: Reemplaza las URLs de imágenes en el archivo `script.js` con tus propias fotografías.
- **Colores**: Modifica las variables de color en el archivo `styles.css` para adaptar la paleta de colores a tu marca.
- **Contenido**: Actualiza los textos en `index.html` para reflejar tu información personal y servicios.

## Tecnologías Utilizadas

- HTML5
- CSS3 (Flexbox, Grid, Animaciones)
- JavaScript (ES6+)
- Font Awesome (para iconos)
